# 故事封面

七张封面使用内置 ImageGen 逐张生成，并保存在 `Fable/Assets.xcassets/` 的对应 `cover-*.imageset` 中。

统一提示词：正方形、无文字的文学寓言封面；细线与水粉画风，暖纸张质感；克制、安静的编辑设计；奶油白、森林绿、陶土橙与浅蓝灰；缩小后主题仍能辨认；无边框、标志或水印。

| 资源 | 故事画面提示 |
| --- | --- |
| `cover-bakery` | 清晨石城门，面包马车因为新收费改走另一条路 |
| `cover-lanterns` | 雾港中封好的航灯木箱，有的灯亮、有的暗 |
| `cover-wheat-price` | 麦田旁的预言公告板，商人观察它对市场的影响 |
| `cover-tall-wheat` | 木尺量着异常高的麦秆，麦穗却很稀疏 |
| `cover-bridge` | 河上的木桥与出现裂纹的梁，岸边留着桥匠账本 |
| `cover-blue-sail` | 灯塔窗外雾中的蓝帆，暗示不确定的证据 |
| `cover-riverside` | 留白的河岸和可拆木台，远处是村庄与河流 |
