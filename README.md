# Fable

每天用一则短寓言理解一个高阶概念。SwiftUI 版本可离线阅读，个人状态默认保存在本机。

## 运行

1. 用 Xcode 27 打开 `Fable.xcodeproj`。
2. 在顶部选择 **Fable** scheme 和一个 iPhone 模拟器。
3. 按 **⌘R** 构建并运行。

离线使用不需要服务器或 API Key。如果使用真机，先在 Xcode 的 **Signing & Capabilities** 中选择自己的开发团队。

## 已实现

- 今日寓言：从内置的七篇故事中按日期轮换。
- 七张独立的故事封面；生成方式和画面提示记录在 [封面说明](docs/cover-art.md)。
- 故事正文连续滚动阅读，离开时保存最近阅读的小节；读到末尾再进入猜想，选项解释、理论、业务映射、相近概念辨析和词源随后展开。
- 读到解析结尾才记为完成；完成后的故事可以随时练习，第二天起会显示待复习状态。答对后按 3、7、14 天安排下一次复习，答错则次日再练。
- 故事库可按标题或概念搜索，也可按主题分类筛选。
- “我的”展示最多三条复习卡、可横向浏览近一年的学习活跃日历、基于阅读和收藏的主题倾向；已学概念按概念去重，全部概念和收藏进入独立列表。
- 设置中可调整正文字号并开启 iCloud 同步。阅读进度、复习、活跃事件与字号偏好都保存在本机，旧版已读和收藏记录会迁移。

## iCloud 同步

项目已包含 iCloud Key-value Storage entitlement 和按设备合并的同步逻辑。要在真实设备间启用，需要：

1. 在 Xcode 中配置自己的开发团队和稳定、唯一的 Bundle Identifier。
2. 为该 App ID 开启 iCloud Key-value Storage，并使用同一 Apple 账户登录设备。
3. 通过正确签名的 App 构建或分发。未签名的模拟器构建只验证界面及本地读写，无法证明跨设备同步已生效。

同步的是学习状态与设置，故事正文和封面仍随 App 打包。活跃事件保留最近 400 天，以控制云端数据量。通知与内容后台尚未加入。
